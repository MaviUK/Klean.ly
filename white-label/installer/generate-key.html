Only use this to set up the Klean.ly Business control-plane encryption key, not a Supabase service-role key or database password.

Generated on this device only

The key is created using your browser's built-in cryptographic random-number generator. This page never sends it to Klean.ly, Netlify or anyone else.

Paste the key as the Value for KLEANLY_OAUTH_ENCRYPTION_KEY in Netlify. Mark it as secret and allow Functions scope only. Keep a secure backup in your password manager: losing the key will make existing encrypted connections unreadable. Do not share screenshots of the generated value.
