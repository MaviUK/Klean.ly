STEP 02 — INFRASTRUCTURE

Owned by the company.

Each company uses a completely separate Supabase project and hosting site. The production connector will request permission to create and configure these resources.

Supabase connection security

When the permanent connection is enabled, authorising creates an account-bound grant encrypted on the Klean.ly Business server. You can reconnect, check, sign out or disconnect. Until the secure storage is enabled, the original verification-only test remains available. No customer project is installed or changed at this stage.
